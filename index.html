Panduan Lengkap

1. Generator

Konfigurasi Dataset — pilih topik, bahasa output, sumber teks, target token, jumlah file, format (JSON/JSONL), dan prefix nama file.

Sumber Teks — Sintetis memakai template bawaan. Hybrid menggabungkan korpus + template. Korpus saja murni dari korpus yang sudah dimuat.

2. Mode Output

Kolom Kustom — bangun struktur JSON via field builder. Tersedia presets (Instruction, Chat, Dokumen, Klasifikasi, Q&A, Code). Setiap field mendukung tipe nilai dan template placeholder.

Label JSON Kustom — tulis sendiri template JSON/JSONL, lalu isi Jumlah Entri. Kosongkan nilai string ("") untuk auto-fill berdasarkan nama key. Contoh:

{"text":""}
{"instruction":"","output":""}
{"messages":[{"role":"user","content":"{sentence}"},{"role":"assistant","content":"{paragraph}"}]}

Anda juga bisa menyisipkan placeholder seperti {sentence}, {paragraph}, {title}, {code}, {number:1-100}, {uuid}, {date}, dsb.

3. Kontrol Kualitas

Near-Duplicate — ambang jarak Hamming (0–20). Semakin besar = semakin longgar pengecekan duplikat.

Min. Unique-Word Ratio — rasio minimal kata unik per teks. Teks di bawah ambang akan ditolak.

Max Retry — batas percobaan membuat record unik sebelum menyerah.

4. Struktur Kolom (Field Builder)

Setiap baris = satu kolom di output. Kolom Nama Kolom menentukan key JSON. Kolom Tipe menentukan generator nilai otomatis. Kolom Template opsional — jika diisi, nilainya dirender dari template.

Jika nama kolom dikenali (id, uuid, email, url, question, answer, label, dst.), tipe auto akan otomatis menyesuaikan.

5. Memori Duplikat

Upload file JSON/JSONL/ZIP untuk diambil fingerprint-nya. Fingerprint disimpan di IndexedDB agar bertahan antar sesi. Semua generate berikutnya akan menghindari fingerprint ini.

6. Corpus Library

Dari GitHub Releases — fetch otomatis asset dengan pola corpus-<lang>-<id>. Klik Load untuk mengunduh & simpan ke perangkat.

Upload Manual — pilih banyak file sekaligus. Mendukung .json, .jsonl, .zip, .txt.

7. Template Library

Konsep sama dengan Corpus, tapi pola filenya template-<lang>-<id> dan isinya satu template per baris. Template aktif akan dipakai sebagai basis kalimat sintetis.

Import Manual — pilih banyak file .txt/.json/.jsonl/.zip. Baris yang dibaca akan digabung dengan template yang sudah ada.

8. Download

Jika hanya 1 file, hasil diunduh langsung (JSON atau JSONL). Jika >1 file, otomatis dikemas menjadi ZIP.

9. Tema & Bahasa

Klik tombol ☀/☾ di kanan atas untuk beralih Dark / Light. Klik tombol ID / EN untuk beralih bahasa antarmuka.
